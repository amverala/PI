!!! info "Bienvenido/a"

    Esta web te acompañará durante todo el desarrollo del Proyecto Intermodular I del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).

    Aquí encontrarás explicaciones, ejemplos, plantillas y recursos para construir paso a paso la memoria del proyecto.

---

## ¿Qué es el Proyecto Intermodular?

El Proyecto Intermodular permite aplicar conocimientos adquiridos en distintos módulos del ciclo para diseñar, analizar y documentar una propuesta de aplicación web.

Durante 1.º DAW el objetivo principal será:

- Analizar problemas reales.
- Identificar usuarios y necesidades.
- Definir objetivos y alcance.
- Planificar un proyecto.
- Elaborar una memoria profesional.

!!! success "Importante"

    Durante 1.º DAW construiremos principalmente la memoria del proyecto.

    La implementación completa de la aplicación se realizará principalmente durante 2.º DAW.

## Objetivo final

Al finalizar el Proyecto Intermodular I deberás ser capaz de presentar una propuesta de aplicación web:

- Bien definida.
- Correctamente documentada.
- Viable técnicamente.
- Planificada de forma realista.
- Preparada para su desarrollo posterior.

> "Un proyecto bien documentado comienza mucho antes de escribir la primera línea de código."

# Definición de objetivos

## ¿Qué es un objetivo?

Un objetivo describe el resultado que queremos conseguir con el proyecto.

Responde a la pregunta:

> ¿Qué pretendemos lograr?

!!! info "Idea clave"

    Los objetivos describen resultados.

    Las funcionalidades describen cómo se alcanzan esos resultados.

## Objetivos y funcionalidades no son lo mismo

### Incorrecto

- Tener login.
- Tener base de datos.
- Tener menú principal.

### Correcto

- Permitir el acceso seguro a usuarios registrados.
- Facilitar la gestión de reservas deportivas.
- Mejorar la organización de las instalaciones.

## Características de un buen objetivo

| Característica | Pregunta |
|---|---|
| Claro | ¿Se entiende fácilmente? |
| Medible | ¿Podemos comprobar si se ha conseguido? |
| Alcanzable | ¿Es realista para DAW? |
| Relevante | ¿Ayuda a resolver el problema? |

## Objetivos generales y específicos

### Objetivo general

Facilitar la gestión de reservas deportivas mediante una aplicación web.

### Objetivos específicos

- Permitir consultar horarios disponibles.
- Gestionar reservas online.
- Reducir llamadas telefónicas.
- Mejorar la organización de instalaciones.

## Justificación y criterio de logro

| Objetivo | Justificación | Criterio de logro |
|---|---|---|
| Permitir reservas online | Reducir llamadas | Un usuario puede reservar desde la web |
| Consultar disponibilidad | Mejorar acceso a información | La aplicación muestra horarios actualizados |

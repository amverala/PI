# 2. Definición del proyecto

## 2.1 Descripción general del proyecto

Actualmente la gestión de reservas de instalaciones deportivas municipales se realiza principalmente mediante atención telefónica y presencial. Esta situación dificulta la consulta de horarios actualizados, genera una elevada carga administrativa y provoca incidencias relacionadas con errores de comunicación y disponibilidad.

Para mejorar esta situación se propone desarrollar una aplicación web denominada **ReservaSport**, destinada a la gestión de reservas deportivas municipales.

La aplicación permitirá consultar la disponibilidad de instalaciones, realizar reservas y gestionar usuarios registrados.

El sistema estará dirigido principalmente a los ciudadanos usuarios de las instalaciones deportivas y al personal administrativo responsable de su gestión.

El alcance inicial del proyecto se centrará en la consulta de horarios, la gestión de reservas y la administración básica de usuarios. Funcionalidades más avanzadas, como los pagos online o las aplicaciones móviles nativas, quedan fuera de esta primera versión y podrán considerarse como futuras ampliaciones.

La propuesta pretende mejorar la accesibilidad al servicio, reducir la carga administrativa y ofrecer una experiencia más cómoda a los usuarios.

## Alcance inicial

### Incluido

- Gestión de usuarios.
- Consulta de disponibilidad.
- Realización de reservas.
- Cancelación de reservas.

### No incluido

- Pagos online.
- Aplicación móvil.
- Notificaciones avanzadas.

### Futuras ampliaciones

- Pagos electrónicos.
- Estadísticas.
- Aplicación móvil.

## 2.2 Definición de objetivos

### Objetivo general

Facilitar la gestión de reservas deportivas municipales mediante una aplicación web accesible desde cualquier dispositivo con conexión a Internet.

### Objetivo específico 1

**Descripción**

Permitir a los usuarios consultar la disponibilidad de instalaciones deportivas en tiempo real.

**Justificación**

Mejorar el acceso a la información.

**Criterio de logro**

Los usuarios pueden consultar horarios y disponibilidad desde la aplicación.

### Objetivo específico 2

**Descripción**

Permitir la realización de reservas online.

**Justificación**

Reducir la dependencia de la atención telefónica.

**Criterio de logro**

Los usuarios registrados pueden realizar reservas desde la aplicación.

### Objetivo específico 3

**Descripción**

Facilitar la gestión administrativa de las instalaciones deportivas.

**Justificación**

Mejorar la organización del servicio.

**Criterio de logro**

El personal administrativo puede consultar, modificar y cancelar reservas.
